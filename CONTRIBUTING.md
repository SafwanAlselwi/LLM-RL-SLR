# Contributing

Thank you for helping improve this survey repository.

## Good contributions

- Corrections to bibliographic metadata
- Broken-link reports
- Reproducibility fixes
- Clarifications to the codebook
- Corrections to extracted study-level fields, with a source citation
- Website accessibility or rendering fixes

## Before opening a pull request

1. Describe exactly what changed and why.
2. For evidence-table corrections, identify the affected study and provide the source page/section supporting the correction.
3. Do not add new corpus studies without explaining how they meet the stated inclusion logic and how denominators/tables should be updated.
4. If a change affects quantitative results, rerun the reproducibility scripts and report the changed outputs.

## Questions

For scientific questions, please use a GitHub Issue so the discussion remains visible and auditable.
